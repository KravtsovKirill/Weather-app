# Иконки

Локальные SVG взяты из [Lucide Icons](https://github.com/lucide-icons/lucide/tree/main/icons). Лицензия — ISC; её полный текст сохранён в [`LICENSE-lucide.txt`](LICENSE-lucide.txt). Авторские права: Lucide Icons and Contributors. Для возможных элементов, происходящих из Feather, исходный файл лицензии также содержит текст MIT.

Исходные имена совпадают с именами файлов, кроме `history.svg`: это [`rotate-ccw-clock.svg`](https://github.com/lucide-icons/lucide/blob/main/icons/rotate-ccw-clock.svg), переименованный для интерфейса. Остальные файлы: `sun`, `cloud-rain`, `wind`, `map-pin`, `calendar-days`, `shirt`, `user-round`, `sparkle`.
