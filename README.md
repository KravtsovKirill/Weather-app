# Одежда по погоде

Приложение подбирает один комплект одежды на каждый выбранный день. Оно учитывает ответы на квиз из 10 вопросов и прогноз для указанного города: температуру и ощущения, ветер, влажность, дождь, снег и вероятность осадков. Профили и история подборов хранятся в SQLite.

## Запуск

Нужен Python 3.12+ и ключи OpenWeather и OpenRouter.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```

Заполните `OPENWEATHER_API_KEY` и `OPENROUTER_API_KEY` в `.env`. На Windows используйте `.venv\Scripts\activate` и `copy .env.example .env`. Бесплатная модель указана в `.env.example`; её доступность зависит от лимитов сервиса.

## Как работает подбор

Город проверяется через геокодирование. Прогноз собирается из трёхчасовых наблюдений; крайние дни могут быть неполными.

Для каждого дня модель получает погодные показатели и все ответы выбранного профиля, затем возвращает один комплект и короткое объяснение. Весь выбранный прогноз обычно обрабатывается одним запросом. Если новый подбор недоступен, сохранённая история остаётся доступной.

## Публикация

Для Streamlit Community Cloud загрузите исходники в GitHub, укажите `app.py` и внесите ключи в Secrets по образцу `.streamlit/secrets.toml.example`. Не публикуйте `.env`, `.streamlit/secrets.toml` и `data/`. На этом хостинге локальная SQLite база может быть сброшена при перезапуске приложения.
